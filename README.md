## 📌 Project Overview
This project analyzes the Instagram performance of **Sugar Cosmetics** using **Tableau**. The objective is to evaluate engagement, reach, content performance, audience trends, and provide data-driven recommendations to improve the brand's social media strategy.

---

## 🎯 Project Objectives
- Analyze Instagram engagement and reach.
- Identify top-performing posts and content types.
- Evaluate posting trends over time.
- Compare performance across Images, Videos, and Carousels.
- Analyze hashtag effectiveness.
- Recommend strategies to improve engagement and follower growth.
